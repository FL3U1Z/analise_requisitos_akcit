# Histórias de Usuário

Sistema de Gestão de Eventos — Empresa Eventus

Formato adotado (Unidade III): **Como** \<tipo de usuário\>, **quero** \<funcionalidade\>, **para** \<benefício esperado\>.

As histórias cobrem as principais funcionalidades identificadas na análise. Cada história referencia os requisitos funcionais (`RF`) correspondentes. Os critérios de aceitação detalhados estão em `criterios-de-aceitacao.md`.

## Participante

**HU-01 — Ver eventos disponíveis** *(RF-01)*
Como participante, quero visualizar todos os eventos disponíveis em um único lugar, para escolher em quais me inscrever sem precisar procurar em vários canais.

**HU-02 — Inscrever-se em um evento** *(RF-02, RF-04)*
Como participante, quero me inscrever em um evento e receber um comprovante logo em seguida, para confirmar que minha participação foi registrada.

**HU-03 — Inscrever-se em vários workshops** *(RF-03)*
Como participante, quero me inscrever em mais de um workshop no mesmo dia, para aproveitar várias atividades do evento — desde que não tenham horários conflitantes.

**HU-04 — Acompanhar minhas inscrições** *(RF-05)*
Como participante, quero acompanhar o status das minhas inscrições, para saber se estão confirmadas, pendentes de pagamento ou em lista de espera.

**HU-05 — Cancelar inscrição** *(RF-06)*
Como participante, quero cancelar minha inscrição sozinho quando não puder participar, para não precisar entrar em contato com a organização.

**HU-06 — Entrar na lista de espera** *(RF-08)*
Como participante, quero entrar em uma lista de espera quando o evento estiver lotado, para ter chance de participar caso uma vaga seja liberada.

**HU-07 — Emitir certificado** *(RF-07)*
Como participante, quero emitir meu certificado após o evento, para comprovar minha participação.

## Organizador

**HU-08 — Criar evento** *(RF-09, RF-16)*
Como organizador, quero criar eventos definindo se são gratuitos ou pagos e quantas vagas têm, para disponibilizá-los aos participantes com as regras corretas.

**HU-09 — Controlar vagas automaticamente** *(RF-10, RF-12)*
Como organizador, quero que o sistema controle as vagas automaticamente e gerencie a lista de espera, para não precisar acompanhar manualmente o preenchimento.

**HU-10 — Acompanhar inscritos em tempo real** *(RF-11)*
Como organizador, quero acompanhar a quantidade de inscritos em tempo real, para tomar decisões sobre o evento com informação atualizada.

**HU-11 — Definir política de cancelamento** *(RF-13)*
Como organizador, quero definir se um evento aceita cancelamento de inscrição, para refletir a política de cada evento.

## Equipe Financeira

**HU-12 — Confirmar pagamento antes de liberar inscrição** *(RF-17)*
Como membro da equipe financeira, quero que determinadas inscrições só sejam liberadas após a confirmação do pagamento, para garantir que apenas participantes pagantes ocupem as vagas desses eventos.

**HU-13 — Controlar reembolsos** *(RF-18)*
Como membro da equipe financeira, quero controlar os reembolsos conforme a regra de cada evento, para tratar corretamente os cancelamentos de eventos pagos.

## Palestrante

**HU-14 — Consultar programação e inscritos** *(RF-19, RF-20)*
Como palestrante, quero consultar a programação e a lista de participantes das minhas atividades, para me preparar adequadamente — respeitando os limites de privacidade dos dados dos participantes.
